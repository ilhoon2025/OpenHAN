## 🇰🇷 Proudly Made in Korea

### A New Document Editing Experience, Born in South Korea

**OpenHAN is an open-source word processor entirely conceived and developed by Korean developers.**

Designed with the document-editing needs of Korean users in mind, OpenHAN brings HWP/HWPX editing, AI spell checking, formal-style rewriting, and local AI background removal together — on your **PC and your phone**.

**Developed in Korea. Open to Everyone.**

## ✨ Key Features

### 📄 HWP & HWPX Support

Open, edit, and save HWP 5.0 and HWPX documents. Use OpenHAN's native `.ohan` format to preserve editor-specific formatting.

HWP/HWPX files saved by OpenHAN were opened in Hancom Office Hangul 2024 and kept their fonts, sizes, colors, cell shading, merged tables, images, and page size.

### ✨ OpenHAN AI

#### 🤖 An assistant that can do anything in the app

Tell it what you want and it does it: write reports, official letters and résumés, build tables, change formatting, page setup and themes, fix spelling, and save. (`Ctrl+K, A`)

Press `F8` to check the document. Results show an accuracy score, error-type bars, and fix cards; mistakes get a wavy underline in the document. Fix everything with `Ctrl+F8` or **Fix all**.

  <img src="docs/images/ai-spell.png" alt="Spell check infographic" width="680">

#### 🏛️ Official / academic style rewriter

Turn casual writing into **Korean official-document style**, **academic paper style**, report style, polite notice, or plain language — compare side by side before applying.

  <img src="docs/images/ai-style.png" alt="Official-style conversion" width="680">
</p>

#### 📱 HWP summary & medium viewer

Skim a long HWP without opening it: a phone-style card view with a one-line summary, key points, section summaries, images, and tables. (`Ctrl+K, P`)

<p align="center">
  <img src="docs/images/ai-cards.png" alt="HWP summary card viewer" width="680">

#### 🔑 Free AI with automatic failover

No cloud AI is truly unlimited for free, so you can add **free API keys** from several providers and OpenHAN moves to the next one when a limit is reached. It works without any key via Pollinations, and a **local AI (Ollama)** on your PC is unlimited and keeps documents on your machine.

<p align="center">
  <img src="docs/images/ai-settings.png" alt="AI provider settings" width="680">
</p>

> API keys are stored in your OS account's encrypted storage. Text is sent only when you use an AI feature, and only to the provider used at that moment. For sensitive documents, enable only the local AI.

### 🖼️ Images & AI Background Removal

Remove image backgrounds **locally** with a bundled U²-Net model on ONNX Runtime. Refine with the magic wand, eraser, and restore brush, then insert into the document or save as a transparent PNG — no internet required.

### ✍️ Editing

Fonts, size, color, letter spacing, line spacing, alignment (including distributed), indentation, tables (merge/split cells), images, symbols, hyperlinks, page breaks, page numbers, and page setup (portrait/landscape, margin presets).

`Alt+L` character shape, `Alt+T` paragraph shape, `Ctrl+N, T` new table, `Ctrl+Y` delete line, `F5` cell block, and more. Press `F1` to search them all.

Get the files from the [**Releases page**](https://github.com/ilhoon2025/OpenHAN/releases/tag/v2.5.0).

| 🪟 Windows (portable) | `OpenHAN-2.5.0-Portable.exe` | Runs without installing |

| 🍎 macOS (Apple silicon) | `OpenHAN-2.5.0-mac-arm64.dmg` | M1–M4 Macs. First launch: **right-click → Open** (or `xattr -cr /Applications/OpenHAN.app`) |

> **Windows SmartScreen may warn on first launch** because the app is not code-signed. Click **More info → Run anyway**.

### 📂 Set as default app

On first launch OpenHAN asks whether to open hwp · hwpx · ohan · txt · html files. Click **Set up**, then press **Set default** in Windows Settings. You can do this later in **Tools → Preferences → General**.

## 📖 Quick Start

1. 🆕 **New:** pick a template on the start screen or press `Alt+N`
2. 📂 **Open:** `Ctrl+O` for HWP, HWPX, OHAN, TXT, HTML
3. ✍️ **Edit:** format text and add tables or images
4. ✨ **AI:** open the assistant with `Ctrl+K, A` and ask, e.g. "write meeting minutes" or "make this official style"
5. 🔤 **Spelling:** `F8` to check, `Ctrl+F8` to fix automatically
6. 🪄 **Background removal:** select an image and press `Ctrl+Shift+K`
7. 💾 **Save:** `Ctrl+S` as HWP, HWPX, or OHAN

  <img src="https://github.com/user-attachments/assets/2c353bab-ec23-4d5a-88be-7c5d10b587bc" alt="Save dialog" width="560">

8. 📤 **Share:** export to PDF or print with `Ctrl+P`
9. 🎨 **Preferences:** themes, AI, and default app in **Tools → Preferences**

### Compatibility Notes

HWP 3.0 and earlier, password-protected HWP, and distribution-protected HWP are not supported.

Headers/footers, footnotes, drawing shapes, and table captions are not read or written yet. Some OpenHAN-specific formatting (bullets, quotes) becomes plain paragraphs in HWP/HWPX; use **OHAN** to keep everything.

## 🛠️ Technology Stack

| Area | Technology |
| :--- | :--- |
| Desktop app | Electron |
| Android app | Capacitor |
| User interface | React |
| Editor engine | Tiptap / ProseMirror |
| HWP/HWPX | In-house implementation based on Hancom's published format specs · fflate · cfb |

| Background removal | U²-Net · ONNX Runtime (local) |

OpenHAN uses open-source technology from around the world, while **the planning and development of the OpenHAN application were carried out by Korean developers.**
